● 当前的刷新机制是纯手动触发的，没有自动刷新。具体情况：

  现有的刷新触发点

  ┌─────────────────────┬───────────────────────────────────────────────────┐
  │      触发时机       │                     刷新范围                      │
  ├─────────────────────┼───────────────────────────────────────────────────┤
  │ 切换 Tab（总览/成员 │ useEffect([activeTab]) 重新拉取对应 Tab 数据      │
  │ /设置）             │                                                   │
  ├─────────────────────┼───────────────────────────────────────────────────┤
  │ 选中项目            │ fetchStats + fetchPipelines                       │
  ├─────────────────────┼───────────────────────────────────────────────────┤
  │ 选中管线            │ fetchRecords（焊口矩阵）                          │
  ├─────────────────────┼───────────────────────────────────────────────────┤
  │ CRUD 操作后         │ 新建/编辑/删除项目、新增管线/焊口、导入 Excel、上 │
  │ onRefresh 回调      │ 传照片、驳回照片、批量删除等操作完成后各自调用    │
  └─────────────────────┴───────────────────────────────────────────────────┘

  缺失的场景

  ┌────────────────────┬────────────────────────────────────────────────────┐
  │        场景        │                        问题                        │
  ├────────────────────┼────────────────────────────────────────────────────┤
  │ 施工人员手机上传照 │ 管理台页面不会自动感知，需管理员手动点击管线或切换 │
  │ 片后               │  Tab 才能看到最新状态                              │
  ├────────────────────┼────────────────────────────────────────────────────┤
  │ 浏览器从后台切回   │ 没有 visibilitychange 监听，不会自动刷新           │
  ├────────────────────┼────────────────────────────────────────────────────┤
  │ 多管理员同时操作   │ 没有轮询或 WebSocket，一个管理员的操作对另一个管理 │
  │                    │ 员不可见直到手动刷新                               │
  ├────────────────────┼────────────────────────────────────────────────────┤
  │ 页面无手动刷新按钮 │ 用户只能通过切换 Tab                               │
  │                    │ 或点击管线来间接触发刷新，没有显式的"刷新"按钮     │
  └────────────────────┴────────────────────────────────────────────────────┘

  如果你需要补一个轻量的刷新方案，最实用的是页面获得焦点时自动刷新（visibilitych
  ange 或 focus 事件）——零额外依赖，一行 useEffect 解决。需要我加上吗？
